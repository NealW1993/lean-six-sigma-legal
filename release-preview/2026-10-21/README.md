# Current UI preview - October 21, 2026

Open [the image gallery](index.html). These are real Flutter widget renders of
the current app with fictional example data, captured in an isolated Windows
test process. Android images show the Android layout; they are not captures
from a signed Play release. No customer records, secrets or live AI results
are included. Light and dark themes are represented.

- `windows/`: 10 clean 1920 x 1080 app captures, without added advertising.
- `android/`: 8 clean 1080 x 1920 Android-layout captures.
- `android-captioned/`: 8 alternative phone layouts with descriptive headings.
- `duo/`: 3 Windows + Android marketing compositions, 2560 x 1440.

Check screenshots against the final signed app before uploading. Use clean
Windows images for Microsoft screenshot slots; do not use the duo artwork or
captioned phone images in those slots. Play phone slots accept at most eight
images, not both complete alternatives. Some pictured features require Pro.

This is not a store release announcement, security certification or claim of
App Store availability. Apple drafts are not published here. See
[release status](../../RELEASE_STATUS.md) for outstanding validation.
